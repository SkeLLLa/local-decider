# @ziptie-soft/local-decider-core

Shared library for [local-decider](https://github.com/ziptie-soft/local-decider): `/v1/systemone`
types and client, the policy schema and loader, redaction, truncation and the decision cache.

You rarely install this directly. It is a dependency of the
[`@ziptie-soft/local-decider`](https://www.npmjs.com/package/@ziptie-soft/local-decider) gateway
and the [Paseo plugin](https://www.npmjs.com/package/@ziptie-soft/paseo-plugin-local-decider).

```sh
npm install @ziptie-soft/local-decider-core
```

Requires Node.js 24 or later. Licensed under Apache-2.0.
